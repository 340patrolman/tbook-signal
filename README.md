# T-Book 신호

교통경찰이 **사거리에서 신호기를 조작할 때** 그 교차로가 지금 몇 현시로 몇 초씩 도는지 보는 도구.

- 단일 HTML 한 장. 빌드 없음, 서버 0대.
- **통신 없음** — `connect-src 'none'`. 자료가 파일 안에 있어 지하차도에서도 뜬다.
- 위치는 기기 안에서만 쓴다. 밖으로 나가는 것이 없다.

## 무엇을 보여주나
교차로 이름 · 주기(초) · 현시 수 · 옵셋 · **A링/B링 현시 막대**(칸 너비 = 그 현시의 초) ·
오늘 시간대별 주기. A링과 B링이 다르면 **겹침현시**(좌회전 선행·후행)라고 알린다.

## 자료
- 경찰청 **교차로기반정보서비스** · **교차로계획정보서비스** (공공데이터포털 data.go.kr)
- 신호계획 **2026-09-10 01:00** 수집 · 교차로 목록 갱신일 2024-07-01
- 교차로 398곳 · 운영계획 12,205행 · 요일계획 2,716행

## 한계 — 쓰기 전에 알아야 할 것
- **경찰청이 공개하는 서울 교차로는 388곳뿐이다.** 성모병원·반포·고속터미널·교대역·
  남부터미널 사거리는 목록에 없다(이름으로 조회해도 0건). 덜 받은 것이 아니다.
- **계획값이다.** 감응식·수동 운영 중에는 실제와 다르다.
- 자료에 **주기 시작 절대시각이 없다.** 그래서 「몇 초 뒤 바뀜」은 알 수 없다.
  주기와 현시 길이는 알 수 있고, 그것이 조작에 필요한 값이다.
- 300m 안에 자료가 없으면 **「이 자리에는 자료가 없습니다」**라고 말한다.
  가까운 다른 교차로 값을 이 자리 것처럼 보여주지 않는다.
- 요일코드(1=일 … 7=토)는 문서에 뜻이 없어 **388곳 패턴에서 유추**했다.
  요일계획이 지정되지 않은 67곳은 기본계획을 쓰고 화면에 그렇게 밝힌다.

## T-Book 에서 넘어올 때
`index.html#lat=37.49988&lon=126.98498` 처럼 좌표를 붙이면 그 자리로 바로 연다.
T-Book 이 이미 잡은 좌표를 넘겨받아 **GPS 를 두 번 켜지 않는다.**

## 출처 표시
공공데이터 이용허락 조건에 따라 화면 하단에 **「자료 · 경찰청, 공공데이터포털(data.go.kr)」**
을 상시 표기한다.
